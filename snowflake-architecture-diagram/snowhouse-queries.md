# Snowhouse SQL Queries for Architecture Diagram

All queries target `SNOWHOUSE_IMPORT_SHARE_DB.<DEPLOYMENT>.JOB_RAW_V` with filters:
- `ACCOUNT_ID = <ID>`
- `CREATED_ON >= DATEADD('month', -6, CURRENT_TIMESTAMP())`
- Use `timeout_seconds: 300`

## 1. Total Queries + Date Range

```sql
SELECT COUNT(*) AS TOTAL_QUERIES, MIN(CREATED_ON) AS EARLIEST, MAX(CREATED_ON) AS LATEST
FROM SNOWHOUSE_IMPORT_SHARE_DB.<DEPLOYMENT>.JOB_RAW_V
WHERE ACCOUNT_ID = <ID>
AND CREATED_ON >= DATEADD('month', -6, CURRENT_TIMESTAMP())
```

## 2. Users

```sql
SELECT USER_NAME, COUNT(*) AS QUERY_COUNT,
  ROUND(SUM(TOTAL_DURATION)/1000/3600, 1) AS TOTAL_HOURS
FROM SNOWHOUSE_IMPORT_SHARE_DB.<DEPLOYMENT>.JOB_RAW_V
WHERE ACCOUNT_ID = <ID>
AND CREATED_ON >= DATEADD('month', -6, CURRENT_TIMESTAMP())
GROUP BY 1 ORDER BY 2 DESC LIMIT 20
```

## 7. Feature Detection

```sql
SELECT 
  CASE
    WHEN UPPER(DESCRIPTION) LIKE '%SNOWFLAKE.CORTEX%' OR UPPER(DESCRIPTION) LIKE '%COMPLETE(%' OR UPPER(DESCRIPTION) LIKE '%SENTIMENT(%' OR UPPER(DESCRIPTION) LIKE '%SUMMARIZE(%' THEN 'CORTEX_AI'
    WHEN UPPER(DESCRIPTION) LIKE '%SNOWFLAKE.ML%' OR UPPER(DESCRIPTION) LIKE '%FORECAST%' OR UPPER(DESCRIPTION) LIKE '%ANOMALY%' THEN 'ML_FUNCTIONS'
    WHEN UPPER(DESCRIPTION) LIKE '%DYNAMIC TABLE%' THEN 'DYNAMIC_TABLES'
    WHEN UPPER(DESCRIPTION) LIKE '%SNOWPARK%' THEN 'SNOWPARK'
    WHEN UPPER(DESCRIPTION) LIKE '%NOTEBOOK%' THEN 'NOTEBOOKS'
    WHEN UPPER(DESCRIPTION) LIKE '%STREAMLIT%' THEN 'STREAMLIT'
    WHEN UPPER(DESCRIPTION) LIKE '%CORTEX%SEARCH%' THEN 'CORTEX_SEARCH'
    WHEN UPPER(DESCRIPTION) LIKE '%EXTERNAL%TABLE%' THEN 'EXTERNAL_TABLES'
    WHEN UPPER(DESCRIPTION) LIKE '%ICEBERG%' THEN 'ICEBERG'
    WHEN UPPER(DESCRIPTION) LIKE '%MATERIALIZED VIEW%' THEN 'MATERIALIZED_VIEWS'
    WHEN UPPER(DESCRIPTION) LIKE '%DATA%SHARING%' THEN 'DATA_SHARING'
    WHEN UPPER(DESCRIPTION) LIKE '%CLUSTER%BY%' THEN 'CLUSTERING'
    WHEN UPPER(DESCRIPTION) LIKE '%DOCUMENT%AI%' THEN 'DOCUMENT_AI'
    ELSE 'OTHER'
  END AS FEATURE,
  COUNT(*) AS CNT
FROM SNOWHOUSE_IMPORT_SHARE_DB.<DEPLOYMENT>.JOB_RAW_V
WHERE ACCOUNT_ID = <ID>
AND CREATED_ON >= DATEADD('month', -6, CURRENT_TIMESTAMP())
AND (
  UPPER(DESCRIPTION) LIKE '%SNOWFLAKE.CORTEX%' OR UPPER(DESCRIPTION) LIKE '%SNOWFLAKE.ML%'
  OR UPPER(DESCRIPTION) LIKE '%DYNAMIC TABLE%' OR UPPER(DESCRIPTION) LIKE '%SNOWPARK%'
  OR UPPER(DESCRIPTION) LIKE '%NOTEBOOK%' OR UPPER(DESCRIPTION) LIKE '%STREAMLIT%'
  OR UPPER(DESCRIPTION) LIKE '%CORTEX%SEARCH%' OR UPPER(DESCRIPTION) LIKE '%EXTERNAL%TABLE%'
  OR UPPER(DESCRIPTION) LIKE '%ICEBERG%' OR UPPER(DESCRIPTION) LIKE '%MATERIALIZED VIEW%'
  OR UPPER(DESCRIPTION) LIKE '%DATA%SHARING%' OR UPPER(DESCRIPTION) LIKE '%CLUSTER%BY%'
  OR UPPER(DESCRIPTION) LIKE '%COMPLETE(%' OR UPPER(DESCRIPTION) LIKE '%SENTIMENT(%'
  OR UPPER(DESCRIPTION) LIKE '%SUMMARIZE(%' OR UPPER(DESCRIPTION) LIKE '%FORECAST%'
  OR UPPER(DESCRIPTION) LIKE '%ANOMALY%' OR UPPER(DESCRIPTION) LIKE '%DOCUMENT%AI%'
)
GROUP BY 1 ORDER BY 2 DESC
```

## 10. SQL Command Categories

```sql
SELECT
  CASE
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%COPY INTO%' THEN 'COPY_INTO'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%MERGE%' THEN 'MERGE'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%CALL%' AND UPPER(LEFT(DESCRIPTION, 50)) NOT LIKE '%SYSTEM$%' THEN 'STORED_PROCS'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%CREATE%TASK%' OR UPPER(LEFT(DESCRIPTION, 50)) LIKE '%ALTER%TASK%' THEN 'TASKS'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%CREATE%STREAM%' THEN 'STREAMS'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%CREATE%PIPE%' THEN 'SNOWPIPE'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%INSERT%' THEN 'INSERT'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%SELECT%' THEN 'SELECT'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%CREATE%TABLE%' THEN 'CREATE_TABLE'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%CREATE%VIEW%' THEN 'CREATE_VIEW'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%UPDATE%' THEN 'UPDATE'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%DELETE%FROM%' THEN 'DELETE'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%TRUNCATE%' THEN 'TRUNCATE'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%SHOW%' OR UPPER(LEFT(DESCRIPTION, 50)) LIKE '%DESCRIBE%' THEN 'METADATA'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%PUT %' THEN 'PUT_FILES'
    WHEN UPPER(LEFT(DESCRIPTION, 50)) LIKE '%GET %' THEN 'GET_FILES'
    ELSE 'OTHER'
  END AS CATEGORY,
  COUNT(*) AS CNT
FROM SNOWHOUSE_IMPORT_SHARE_DB.<DEPLOYMENT>.JOB_RAW_V
WHERE ACCOUNT_ID = <ID>
AND CREATED_ON >= DATEADD('month', -6, CURRENT_TIMESTAMP())
GROUP BY 1 ORDER BY 2 DESC
```

## Deployment Search Order

Standard: VA, VA2, VA3, PROD1, PROD2, PROD3, AZEASTUS2PROD, AWSUSEAST1HASSIUM

If not found, discover via: `SHOW SCHEMAS LIKE '%<PATTERN>%' IN DATABASE SNOWHOUSE_CORE`

Non-standard known deployments: AWSUSEAST2, AWSEUWEST2, AWSCACENTRAL1, GCPUSCENTRAL1, AWSAPSOUTHEAST1SG, etc.
